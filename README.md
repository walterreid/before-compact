# before-compact

A Claude Code plugin that keeps your last turns, verbatim, across a compaction. The plugin itself is the
[`before-compact/`](before-compact/) folder; read [its README](before-compact/README.md) for what
it does and how to install it. The repo root holds [`test/run.sh`](test/run.sh) and
[`CLAUDE.md`](CLAUDE.md), the working rules for this repo.
